# Chaurasiya Traders Billing System — Stock Edition

Mobile-friendly billing app with product catalogue, inventory quantities, automatic stock deduction on saved/shared bills, low-stock warnings, and stock restocking.

Upload `index.html` to the root of your existing GitHub repository, replacing the previous `index.html`, then commit the change. GitHub Pages will redeploy automatically.

Data is stored in the browser's local storage on this device/browser. Download backups regularly. The backup now includes bills, settings, and product stock.
